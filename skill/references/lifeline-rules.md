# 人生时间轴规则

这是 mingtu 区别于其他命理工具的那一层。别的工具给的是**快照**——本命盘加当前大运加未来一两年。
mingtu 给的是**形状**：从出生到九十岁的一条完整曲线，两套体系各自独立推一遍，然后逐年对账。

`lifeline.py` 已经把下面所有规则算完了。你的任务是读懂它输出的字段并把它讲成人话，不是重算。

---

## 一、两条时间轴为什么要叠在一起

八字和紫微是两套**互不相干**的体系，各有各的时间刻度：

| | 八字 | 紫微斗数 |
|---|---|---|
| 大周期 | 大运，十年一步 | 大限，十年一宫 |
| 起点 | 起运岁数因人而异（出生到最近节气的天数÷3），常见 0–9 岁之间 | 由五行局决定（水二局起 2 岁、木三局起 3 岁……火六局起 6 岁） |
| 排列方向 | 阳年男/阴年女顺排，反之逆排 | 阳男阴女顺行十二宫，反之逆行 |
| 年度刻度 | 流年干支 | 流年十二宫 + 流年四化飞星 |

两条轴的**换轨点几乎从不重合**。这不是缺陷，是信息：

- 两条轴同时说"这十年主事业"→ **共振**，可信度高，可以下判断。
- 一条说进、一条说退 → **冲突**，必须如实说"这段时间两套读法相反"，不许和稀泥挑一个好听的说。
- 两条轴的换轨点相隔两三年 → 那几年就是**过渡带**，人生里最容易出现"上一个阶段结束了但下一个还没开始"的悬空感。

字段：`years[].agreement`（逐维度）、`years[].agreement_counts`、`years[].confidence`。

## 二、六个维度

`事业 · 财富 · 婚恋 · 健康 · 学业 · 人际`

八字侧和紫微侧各自独立打一遍分，字段是 `bazi_dims` 和 `ziwei_dims`，合并值在 `dims`。

### 八字侧怎么打的

1. 取该年的流年干与地支藏干，每个都换算成十神。
2. 查十神→维度映射表（见 `ganzhi-tables.md` 第三节末尾）拿到基础分。
3. 乘以**极性**：这个十神所属的五行，是用神（+1）、忌神（−1）、还是不相干（0）。
   这一步是关键——正官对事业是加分项，但只有当官星是喜神时才成立；官星为忌，同样的正官流年就是压力和是非。
4. 婚恋维度对"男命财星／女命官星"额外加权 1.6 倍。
5. 按各维度的**总喂入量**归一化，否则喂入源最多的维度会永远夺冠。
6. 大运自己也有一份六维画像，与流年按 **四六开**（大运 0.4 / 流年 0.6）混合。
   这条对应一个常识：好流年落在坏大运里，天花板是被压住的。

### 紫微侧怎么打的

1. 用流年天干起四化，得到该年的化禄／化权／化科／化忌四颗星。
2. 找出每颗星在**本命盘**上坐哪个宫位。
3. 该宫位在**流年盘**上叫什么名字，这一化就作用于哪个领域。
   化禄 +2.5、化权 +2.0、化科 +1.5、化忌 −3.0；落流年命宫的额外向全维度扩散 0.25 倍。
4. 各维度对应的宫位：事业→官禄，财富→财帛，婚恋→夫妻，健康→疾厄，学业→父母＋官禄，人际→交友＋兄弟。
5. 静态修正：该宫若坐六煞（擎羊陀罗火铃空劫）每颗 −0.8，坐六吉（辅弼昌曲魁钺）加禄存天马每颗 +0.5。

### 分数怎么读

区间大致 −5…+5，**衡量的是结构性倾向，不是概率，更不是事实**。
更重要的是：**绝对分在人与人之间不可比**。一个用神占三个五行的命，一辈子的分都偏正；
用神只占一个五行的命，分数天然偏低。所以真正有意义的是 `cycles[].rank`（这一步在本人十步大运里排第几）
和 `years[].percentile_in_life`（这一年在本人一生中的分位）。

**写判词时永远用相对表述**："这是你十步大运里最好的一步"，而不是"这步大运 0.74 分，属于中上"。

## 三、关键节点怎么判

`events` 字段，三个级别：`major` / `notable` / `minor`。

| 标签 | 触发条件 | 含义 |
|---|---|---|
| 换运 | 该年 == 某步大运起运岁 | 主题换轨，前后一两年是过渡带 |
| 岁运并临 | 流年干支 == 大运干支 | 力量叠加，该年主题放到最大，好坏都加倍 |
| 伏吟 | 流年干支 == 某柱干支 | 该柱所主之事重演、旧事重提 |
| 反吟 | 流年天克地冲某柱 | 该领域面临强制性变动 |
| 冲提纲 | 流年支冲月支 | 事业格局与所处环境整体挪位 |
| 冲日支 | 流年支冲日支 | 配偶宫动，婚恋与自身状态是当年主戏 |
| 合日支 | 流年支合日支 | 感情与合作关系有牵引 |
| 空亡 | 流年支落本命旬空 | 投入见效慢，宜守成 |
| 化忌入 X 宫 | 流年化忌落流年命／夫妻／疾厄宫 | 该宫所主之事当年最耗心力 |
| 化禄入 X 宫 | 流年化禄落流年命／财帛／官禄宫 | 该方向当年最容易有实际收成 |

**"关键转折"的门槛是叠加，不是单项。** 单独一个冲提纲每十二年来一次，算不上转折。
`turning_points` 只收权重 ≥3 的年份（重量级信号算 2 分，普通 major 算 1 分，notable 算 0.5 分），
且最多取十五个。这是有意为之：如果九十年里标出五十个"关键年份"，就等于一个都没标。

## 四、人生阶段怎么分

不要用"童年少年青年中年老年"这种外来刻度硬切。**用他自己的大运切。**

`cycles` 就是天然的分段：每一步大运是一章，`dominant_dimension` 是这一章的主题，
`peak_years` / `trough_years` 是章内的高低点，`major_events` 是章内的情节点。

每步大运内部还要再分两段（字段 `years[].dayun.phase`）：
- **天干段**（前五年）：偏外象，主环境、机会、外部推力
- **地支段**（后五年）：偏内象，主根基、身体、实际落地

很多人"前五年顺后五年滞"或反过来，就是这条。这个颗粒度别的工具都没有，用起来。

叙事分章建议：
1. **底色**——本命格局与先天禀赋，不涉时间
2. **起运之前**——起运岁数之前的那几年，看月柱与年柱
3. **逐步大运**——一步一章，按 rank 决定着墨轻重
4. **当下**——当前大运 + 当前流年 + 未来三年
5. **形状**——把整条曲线的走势说成一句话（早发/晚成/中间高两头低/一路缓升）

第 5 条是全篇的题眼。人最想知道的不是某一年好不好，是**这辈子的形状是什么**。

## 五、时辰未知时怎么办

时辰影响时柱（八字四分之一）和紫微命宫（全盘地基），不能猜。

1. 先用 `dingshichen.py` 拿已发生的人生事件反推。
2. 看 `verdict`：
   - `可用` → 按第一名走，但全文标注"时辰为反推所得"
   - `待定` → 两套盘并行呈现，只讲两盘都同意的部分
   - `不可用` → **老老实实按时辰未知处理**：只做年月日三柱分析，
     不谈子女宫、不谈晚运、不谈紫微十二宫，明说这些看不了
3. 任何情况下都不要为了让报告完整而假装知道时辰。

## 六、口径必须先说清

同一个生辰在不同口径下是不同的盘。开口断事之前先声明用了哪一套：

| 争议点 | mingtu 默认 | 影响面 |
|---|---|---|
| 子时换日 | 晚子时法（`--sect 2`）：日柱仍属当日，时柱以次日干起 | **换日主，全盘翻转**。仅影响 23:00–24:00 出生者 |
| 真太阳时 | 开启（经度校正 + 均时差），需提供出生地 | 可跨时辰，进而换时柱与紫微命宫 |
| 年柱换年 | 立春，非正月初一 | 立春前后数日出生者换年柱 |
| 月柱换月 | 节气，非农历月 | 节气交界日出生者换月柱 |
| 闰月 | 排盘以节气为准，不受闰月影响 | 农历输入时需问清是否闰月 |
| 紫微流派 | 三合派安星与生年四化（iztro 口径） | 与飞星派在四化解读上有出入 |

命主若已有其他软件或老师排的盘，**沿用他那边的口径**并说明，
不要为了用默认值而制造第二套说法。四柱对不上时先查这张表，不要急着说对方错。

## 七、这套算法不能做什么

写在这里是为了让你在被追问时能准确回答，而不是含糊搪塞：

- **不能算生死。** 没有实现，也不会实现。被问到就直说不做。
- **不能定量。** 分数是结构倾向的排序，不是发生概率。不要说"这一年有 70% 概率升职"。
- **不能替代因果。** 同一个盘在不同的社会位置、不同的努力程度下，兑现度差别极大。
  格局讲的是**上限的量级**，大运讲的是**兑现的窗口**，中间那段是人自己填的。
- **不能跨人比较。** 见第二节末尾。
- **两套体系分歧的年份不能强行统一。** 那是数据在说"这里我不知道"。
