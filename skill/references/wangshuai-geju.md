# 旺衰 · 格局 · 用神

这一层是**八字判断的枢纽**。用神定错，后面九十年的时间轴全是反的。
所以本文件的规则由 `paipan.py` 硬编码执行，你的任务是读懂它的输出并解释，不是自己重算。
当你觉得脚本判错时，说出你的理由并标注置信度，不要静默改判。

---

## 一、旺衰四要素

脚本按四个维度打分，输出在 `bazi.wangshuai` 字段：

1. **得令**（权重最高）：日主是否生于当令之月。
   - 当令：日主五行 == 月支主气五行
   - 相：月支生日主
   - 休：日主生月支
   - 囚：日主克月支
   - 死：月支克日主
2. **得地**：日支及其余各支中是否有日主的根。
   - 通根本气 > 通根中气 > 通根余气
   - 根被冲、被合化掉，力量打折
3. **得势**：全局印星与比劫的数量与位置。
4. **得生**：有无有力的印星贴身相生（月干、日支为贴身）。

四项加权后得到 `strength_ratio`，阈值见 `ganzhi-tables.md` 第六节。

## 二、用神取法（脚本按优先级依次尝试）

### 1. 调候优先（《穷通宝鉴》）
气候极端时，调候压倒扶抑。这是最容易被 LLM 忽略的一条。

- 生于亥子丑月（冬），命局寒湿：**急需丙丁火暖局**，无火则一生辛苦，得火则寒谷回春。
- 生于巳午未月（夏），命局燥烈：**急需壬癸水润局**，无水则燥而无成。
- 生于辰戌丑未月（土旺），命局壅塞：**需甲乙木疏土**。
- 金水伤官喜见火，木火伤官喜见水——古法调候口诀，脚本已内置对照表。

调候用神触发条件：月支为子/丑/亥且局中火 < 0.15，或月支为午/未/巳且局中水 < 0.15。

### 2. 扶抑（常规情形）
- 身强 → 用克泄耗：官杀、食伤、财星
- 身弱 → 用生扶：印星、比劫
- 中和 → 看格局成败取用，或以流通为用

### 3. 通关
命局中两股力量对峙（如金木交战、水火相激），取中间通关之神。

### 4. 病药（《神峰通考》）
命局有明显的"病"（某一忌神当权且贴身），能去病者即为药，药神即用神。

### 5. 从格（慎判）
日主极弱且无根无印，全局一气独旺 → 从财/从杀/从儿/从强。
**从格判定必须标注置信度 C**，并在报告里明说"若非从格则结论相反"，同时给出两套读法。
从格看错是命理最常见的翻车点，不要装作确定。

## 三、常见格局

### 正格（以月令透干取格）

| 格局 | 成格条件 | 破格条件 | 人生形态 |
|---|---|---|---|
| 正官格 | 官星清纯，有财印护 | 伤官见官、官杀混杂 | 循规蹈矩，宜体制、专业、稳定路径 |
| 七杀格 | 杀有制（食神制杀/印化杀） | 杀重无制、制杀太过 | 压力中成事，宜竞争性行业 |
| 正印格 | 印星得地，有官杀生 | 财星坏印 | 学术、文教、依托型成功 |
| 偏印格 | 枭神有制或化 | 枭神夺食 | 偏门技艺、专精、晚成 |
| 食神格 | 食神吐秀，身食两旺 | 枭神夺食 | 才艺、口才、生活家 |
| 伤官格 | 伤官配印 / 伤官生财 | 伤官见官无解 | 才气外露，忌居人下 |
| 正财格 | 财有根，身能任财 | 比劫夺财 | 务实积累，稳中求富 |
| 偏财格 | 财旺身强，有食伤生 | 身弱财重 | 机会型财富，人脉广 |
| 建禄格 | 月令为日主禄，有官杀财 | 无官杀财则孤 | 靠自己白手起家 |
| 月劫格 | 月令为羊刃，有杀制刃 | 刃无制 | 刚烈，成败俱大 |

### 特殊格局（出现概率低，判定从严）
一行得气格、化气格、从格、两神成象、专旺格。
凡判特殊格局，必须同时给出"按正格读"的替代结论。

## 四、格局高低（决定人生量级）

同样是正官格，有人做处长有人做科员，差别在这四条：

1. **用神有力无力**：用神是否得令、通根、透干。
2. **有无破坏**：用神被冲、被合、被克。
3. **配合是否流通**：五行是否首尾相生成环，还是断成两截。
4. **大运是否配合**：中年三步大运（约 25–55 岁）走用神方，格局才兑现。

第 4 条最重要，也是**人生时间轴的意义所在**——好格局遇坏运，一生怀才不遇；平常格局遇好运，一样风生水起。
写报告时必须把"先天格局量级"和"后天大运兑现度"分开讲，不要糊成一句"命好"。

## 五、用神与六亲、领域的对应

用神落在哪个十神上，决定这个人靠什么起家：

| 用神类型 | 起家路径 | 关键年份特征 |
|---|---|---|
| 用印 | 靠学历、资质、贵人、平台 | 印星流年考学、升职、拿资格 |
| 用官杀 | 靠组织、职位、责任压力 | 官杀流年上位或被委以重任 |
| 用财 | 靠经营、实务、人脉 | 财星流年进财、成家 |
| 用食伤 | 靠才华、技术、表达 | 食伤流年出作品、创业、生育 |
| 用比劫 | 靠同侪、合伙、自身努力 | 比劫流年得助力，也易破财 |

## 六、忌神的表达方式

忌神当值不等于"倒霉"，它有固定的表达方式，判词要落到具体形态上：

- 忌官杀：压力、是非、上级刁难、身体劳损
- 忌财星：破财、感情纠纷、母亲/长辈健康、耗神
- 忌食伤：口舌、越界、与上级冲突、子女牵累
- 忌印星：拖延、依赖、消息闭塞、母亲相关事
- 忌比劫：破财、合伙纠纷、兄弟朋友牵连、配偶不利

**禁止**把忌神年直接写成"大凶""破财""血光"。写成"这一年的主要消耗在 X 方向，注意 Y"。
