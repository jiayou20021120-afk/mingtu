# 紫微斗数读盘参考

排盘由 iztro 完成，宫位、星曜、四化、大限全部在 `chart.json` 的 `ziwei` 字段里。
本文件是**解读依据**。

---

## 一、十二宫

| 宫 | 主什么 | 在人生时间轴上看什么 |
|---|---|---|
| 命宫 | 本质、性格、一生格局 | 流年命宫决定该年的总基调 |
| 兄弟宫 | 手足、平辈、合伙人；亦看母亲 | 合作与竞争关系的年份 |
| 夫妻宫 | 配偶、亲密关系模式 | 婚恋窗口与危机年 |
| 子女宫 | 子女、创作、下属；亦看性 | 生育、作品产出、带团队 |
| 财帛宫 | 现金流、赚钱方式 | 收入结构变动 |
| 疾厄宫 | 体质、慢性倾向、情绪耗损 | 健康预警窗口 |
| 迁移宫 | 外出、变动、外部机遇 | 搬迁、出国、换环境 |
| 交友宫 | 朋友、下属、人脉质量 | 人际得失 |
| 官禄宫 | 事业、职位、成就形态 | 升迁、转行、创业窗口 |
| 田宅宫 | 不动产、家庭、根据地 | 置产、搬家、家族事 |
| 福德宫 | 精神状态、享受、潜意识 | 心理层面的顺逆，常比命宫更准 |
| 父母宫 | 父母、长辈、上级、文书 | 学业、考试、与权威的关系 |

**三方四正**是紫微读盘的最小单位：任何一宫都要连着它的对宫、财帛位、官禄位一起看，单看一宫必错。

借宫解读一律标注置信度 C。

## 三、辅佐煞星

**六吉**：左辅、右弼（助力、贵人）；文昌、文曲（文书、才华、考试）；天魁、天钺（机遇、提携）
**六煞**：擎羊（刚锐、外伤）；陀罗（拖磨、慢性）；火星、铃星（急躁、突发）；地空、地劫（落空、破耗）
**其余要角**：禄存（实质财禄）、天马（驿动，与禄同宫为"禄马交驰"）

煞星不等于坏。七杀破军贪狼这类开创型主星，**必须见煞才有力**，纯吉反而软。
写判词时不要看到煞就报警。

## 四、四化（人生时间轴的驱动器）

化禄（进）、化权（掌）、化科（名）、化忌（滞）。

四化有三层，别混：
1. **生年四化**——出生年干起，一生不变，是命格的底层驱动。字段 `ziwei.birth_mutagen`。
2. **大限四化**——大限宫干起，管十年。
3. **流年四化**——流年干起，管一年。字段 `years[].flying_mutagen`。

**飞星的读法**：一颗星在本命盘上坐 A 宫，流年时 A 宫的流年名字叫"官禄宫"，
那么这一化今年就作用在事业上。这是 `lifeline.py` 计算紫微侧六维分的全部逻辑，
你在解读时要能把这条链说清楚：**哪颗星 → 本命坐哪宫 → 流年这宫叫什么 → 所以今年动什么**。

化忌最需要谨慎表达。化忌不是灾，是**黏着与执念**——那件事今年会占据你最多的心力，
可能是因为难，也可能只是因为你放不下。

## 五、常见格局（仅在真的成立时才提）

| 格局 | 条件 | 含义 |
|---|---|---|
| 君臣庆会 | 紫微天府得左辅右弼 | 有位有辅，格局大 |
| 府相朝垣 | 天府天相夹拱命宫 | 稳，有资源托底 |
| 机月同梁 | 天机太阴天同天梁四星会 | 宜专业、幕僚、公职，不宜冲锋 |
| 杀破狼 | 七杀破军贪狼三方会 | 一生多变动，靠转折成事 |
| 禄马交驰 | 禄存或化禄与天马同宫 | 动中得财，宜异地发展 |
| 日月并明 | 太阳太阴皆庙旺 | 内外兼顾，声名与实惠俱得 |
| 铃昌陀武 | 铃星文昌陀罗武曲聚 | 古书列为凶格，现代读作"多重压力叠加期"，不作凶断 |

**纪律**：格局名称与实际盘面冲突时，以盘面为准。
不要为了报出一个好听的格局名而放宽条件——这是命理最常见的注水手法。
